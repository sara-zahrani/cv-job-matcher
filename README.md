# CV → Job Matcher

**Modern Data Engineering for Advanced AI Systems** — [SDAIA Academy](https://github.com/SDAIAAcademy)

## Project description

Upload a CV. The system retrieves the job postings, out of those it has already ingested, that fit it best, and explains for each one why it fits and what is missing.
